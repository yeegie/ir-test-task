### 1. Создайте и активируйте виртуальное окружение

``` python
python -m venv .venv
```

Windows
``` bash
.\.venv\Scripts\activate
```

Linux
``` bash
source .venv/bin/activate
```
---

### 2. Установка зависимостей

``` bash
pip install .
```

---

### 3. Убедитесь что файл с токеном лежит в корневой директории

```
ir-test-task/
│
├── token.txt
├── data/
├── src/
├── pyproject.toml
└── ...
```

Внутри файл должен выглядеть так


```
0000000000:AAHQDE9UXsadAWDAWSDwadwa
```

---

### 4. Запуск приложения

``` bash
run_app
```
